# 🚇 Delhi Metro Smart Card Management System

## 📌 Overview

The **Delhi Metro Smart Card Management System** is a Java-based web application designed to streamline metro card operations. The project provides an efficient way to manage smart card services such as card recharge, fare calculation, metro route information, and user-related activities through a simple and interactive interface.

## ✨ Features

* Smart Card Recharge
* Fare Calculation
* Metro Route Information
* User Dashboard
* Admin Dashboard
* Secure Database Connectivity

## 🛠️ Technologies Used

* Java
* JSP
* Servlets
* JDBC
* MySQL
* HTML
* CSS
* Apache Tomcat
* Eclipse IDE
